# 奥比中光 AprilTag 姿态验证

纯视觉独立 demo；不打开真机串口、IMU UDP 或 ROS，不控制任何机器人。

```bash
cd /home/hzb/Work/WT901
conda run --no-capture-output -n OptUSBProj-yolo python demos/apriltag_pose_demo.py
```

关闭 OrbbecViewer 和其他占用相机的程序；点击“启动相机”，等待约两秒预热。
复用主项目现有 `OrbbecWorker` 和独立 `orbbec336l` SDK 子进程，内部仍采集 RGB-D，
本 demo 的检测/姿态只使用 RGB，不用深度求解或验证距离。

## 依赖

当前本机检查：GUI 环境 `OptUSBProj-yolo` 已有 NumPy、PySide6、OpenCV 5.0.0，
包含 `cv2.aruco.ArucoDetector` 和 `DICT_APRILTAG_36h11`；相机环境
`orbbec336l` 已有 pyorbbecsdk 2.9.3。暂时不需要安装新包或下载权重。
不要为本 demo 替换现有 OpenCV 或把 SDK 装入 GUI 环境。

## 尺寸、坐标与可信度

- tag36h11，ID 0 黑框 50 mm、ID 1 黑框 25 mm、ID 2 黑框 16 mm。
- 界面可修改每个 ID 的实际黑框尺寸；白边不算尺寸。错误尺寸会按比例影响距离。
- 使用 SDK 当前彩色内参与 Brown-Conrady 畸变；分辨率不匹配/未知模型会报错，不猜测参数。
- 估计 `T_camera_tag`：`p_camera = R @ p_tag + t`，位置单位米，界面显示毫米。
- 相机 X 右、Y 下、Z 前。标签原点在黑框中心；标准图案方向 X 右、Y 上、Z 朝正面外侧。
- 三个“旋转向量”分量是 Rodrigues 轴角向量的度数表示，不是三个欧拉角。
- 单标签平面可能存在接近的双解。界面提示方向不可靠；坐标轴只代表最佳候选，不是认证真值。
- 重投影 RMS > 3 px、最短边 < 16 px、重复 ID、未知 ID 等会拒绝姿态。
  这些是演示过滤阈值，不是精度或安全保证。低重投影误差也不证明纸面平整或尺寸正确。
- 标签消失不保留旧数值；采集超 1 秒无新帧清空姿态。显示延迟是主机接收至显示，不是曝光至显示。
- 暂无机器人连杆安装标定、关节角恢复、控制闭环、深度一致性或高精度标定。

## 手动验收

### 距离与质量诊断

表格显示最短/平均边长（原始图像像素，不是窗口缩放后的像素）、
PnP 估计中心距离 `‖t‖` 与光轴深度 `Z`、角点重投影 RMS。
默认几何筛选：最短边至少 32 px、重投影不超过 1 px、无接近平面双解。
原有最短边 16 px / 重投影 3 px 的姿态拒绝底线不变。
绿色表示所启用的经验筛选通过；黄色仍可能识别到了 ID，但姿态不足或采样未完成。
筛选不会输出机器人指令，也不是绝对精度或安全认证。

固定相机和纸张后，勾选“测量静止波动”。最近 2 秒内的样本分别计算：

- 位置：相对窗口平均位置的三维距离 RMS，单位 mm。
- 朝向：相对窗口平均旋转的最短旋转角 RMS，单位度，避免直接相减旋转向量。
- 至少 10 帧且跨度 1 秒后，应用默认位置 2 mm / 朝向 2° 的波动阈值。

四项阈值可在界面调整。运动会计入波动，不能在运动时将其解释为测量噪声；
稳定但有系统偏差的结果仍可能通过。切换波动开关、标签消失/重复/姿态拒绝、
尺寸改变、相机停止/出错，以及采样间断超过 0.5 秒会重新开始统计。
分别移动到多个距离并静止约 2 秒，对比三个标签的像素、波动和质量提示，
即可评估当前光照、视角和打印条件下的可用距离；并非标定真值误差。

1. 将 A4 纸平放/固定在硬板上，不要拿着弯曲的纸测精度；先在相机近处识别较大的 ID 0。
2. 检查三个图案分别显示 0/1/2。完整 A4 尺寸不同，距离应大致一致，不保证完全相同。
3. 靠近/远离相机，确认 t 的 Z 随之减小/增大；倾斜纸面，观察坐标轴和双解提示。
4. 用尺测粗略距离作为检查，注意测到标签中心与相机光心的距离，而非外壳前沿。
5. 逐个遮挡标签，旧姿态应消失；停止/重启相机应能释放并重新采集。
6. 小标签检测困难时先靠近、改善光照与清晰度，避免直接用不可靠数值控制真机。
