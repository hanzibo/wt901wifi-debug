# 从 WT901 姿态到 GUI 模型：用 SO(3) 与李代数解释

本文解释本仓库的手腕演示如何把 WT901 回传的 R/P/Y 变成模型姿态，也适用于人体模型中单个骨段的姿态映射。核心链路是：

两台设备分别标定右上臂、右前臂的连续映射，并求肘关节相对旋转的完整流程，见 [人体手臂连续轴映射](CONTINUOUS_ARM_CALIBRATION.md)。

```text
设备 R/P/Y → 姿态矩阵 R(t) → 相对 GUI 零位 ΔR(t)
          → 轴映射 B → 模型相对旋转 Q(t) → 绘制模型
                                      ↘ log(Q)：旋转向量可视化
```

这里讨论的是**绕固定关节的三维旋转**。旋转向量属于三维李代数 `so(3)` 的向量表示；它不是包含平移的六维刚体运动旋量。手腕模型的转轴位置由几何模型预先固定，程序没有从加速度二次积分计算手掌位置。

## 1. 先约定坐标系与记号

采用列向量，矩阵写在向量左侧，旋转矩阵属于

$$SO(3)=\{R\in\mathbb R^{3\times3}\mid R^\mathsf TR=I,\ \det R=1\}. $$

| 记号 | 含义 |
| --- | --- |
| $W$ | 设备融合算法使用的参考坐标系；不必等同于 GUI 世界系 |
| $S_t$ | 时刻 $t$ 的设备本体坐标系 |
| $S_0$ | 点击 GUI 归零时的设备本体坐标系 |
| $M_0$ | GUI 手掌模型的中立局部坐标系 |
| $R(t)={}^{W}R_{S_t}$ | 设备三根轴在 $W$ 中的方向，矩阵的三列分别对应设备 $+X,+Y,+Z$ |
| $B={}^{M_0}R_{S_0}$ | **归零姿势下**设备轴到模型轴的固定映射 |
| $Q(t)$ | 模型从中立姿态到时刻 $t$ 的相对旋转，表达于 $M_0$ |

上下标是表达坐标系，不是额外的物理转动。比如 $B$ 的第一列是设备中立位 $+X$ 轴在模型坐标中的方向。GUI 手动选择“设备 +Z → 模型 +Y”就是在指定 $B$ 的第三列。有效轴映射要求三列正交、长度为 1 且保持右手系，即 $B\in SO(3)$；程序拒绝镜像映射。

## 2. 设备欧拉角组成绝对姿态矩阵

当前程序把一包数据的 Roll、Pitch、Yaw（单位：度）按 ZYX 约定转换：

$$R(t)=R_z(\mathrm{Yaw}_t)R_y(\mathrm{Pitch}_t)R_x(\mathrm{Roll}_t).$$

例如 $R_z(\psi)$ 为

$$R_z(\psi)=\begin{bmatrix}\cos\psi&-\sin\psi&0\\
\sin\psi&\cos\psi&0\\0&0&1\end{bmatrix}.$$

这三个角描述**同一时刻的一个姿态**；不能把每包 R/P/Y 当作新增的角增量连续相乘，也不能用“当前欧拉角减去零位欧拉角”代替三维相对旋转。矩阵乘法不交换，欧拉角在某些姿势还会出现参数突变。实现见 [姿态矩阵转换](../wt901_viz/orientation.py)。ZYX 是本项目当前的软件解释约定；设备自身的安装模式、融合算法和磁场状况仍会影响回传姿态的质量。

## 3. 点击“模型归零”到底做了什么

点击归零时，GUI 把最近一包的 $R(0)$ 保存为 $R_0$，并立即把手掌模型绘制为中立姿势。之后每时刻计算

$$\Delta R(t)=R_0^{-1}R(t)=R_0^\mathsf T R(t).$$

它是“当前设备相对于点击时设备”的有限旋转，表达在**归零时的设备轴 $S_0$**下。归零瞬间 $\Delta R(0)=I$。例如即使设备相对于自身融合参考系已偏航 70°，只要此刻点击 GUI 归零，这 70° 都不直接出现在模型上。

归零不推断“真实手掌解剖学中立位”。若真实手掌稍微屈腕时点击归零，GUI 也会显示模型的预设中立姿势；真实手掌随后伸直，模型可能向相反方向转动。设备固件的“航向归零／X-Y 角度归零”则是另一回事：那是对设备的写操作，可能改变后续输出的 $R(t)$；GUI 归零只改电脑端保存的 $R_0$。两者不应混为一谈。代码见 [手腕程序的归零与相对旋转](../wrist_demo.py)。

## 4. 为什么轴映射要做共轭变换

设备的 $\Delta R$ 表达在 $S_0$ 中，模型需要同一个旋转表达在 $M_0$ 中。先把模型坐标向量用 $B^\mathsf T$ 转到设备中立坐标，施加 $\Delta R$，再用 $B$ 转回来：

$$\boxed{Q(t)=B\,\Delta R(t)\,B^{-1}
=B\,R_0^\mathsf T R(t)\,B^\mathsf T.}$$

这称为旋转矩阵的**共轭**或换基。它没有增加物理运动，只是改变同一运动的坐标表示。归零时

$$Q(0)=BIB^{-1}=I,$$

所以映射不会让模型在归零瞬间偏离中立位。只计算 $B\Delta R$ 则会得到 $B$，不能满足这一要求。

例子：合法映射 `(+X, -Z, +Y)` 表示设备 $+Z$ 对应模型 $+Y$。如果设备相对零位绕自身 $+Z$ 转 30°，即 $\Delta R=R_z(30^\circ)$，那么

$$Q=B R_z(30^\circ)B^\mathsf T=R_y(30^\circ).$$

手动映射是离散的带符号轴排列；人体模型的穿戴标定还可以产生连续的 $3\times3$ 映射矩阵，以表达绑带安装的细小角度偏差。只要 $B\in SO(3)$，上述公式相同。实现见 [共用轴映射校验](../wt901_viz/axis_mapping.py)、[手腕旋转计算](../wrist_demo.py)与[人体模型计算](../OptUSBProj-ubuntu/optusbproj_ubuntu/pose.py)。

## 5. 李群、李代数、伴随作用各在什么位置

$SO(3)$ 是旋转的李群；其李代数 $\mathfrak{so}(3)$ 是所有 $3\times3$ 反对称矩阵。三维向量 $\boldsymbol\phi$ 经“帽”算子变为

$$[\boldsymbol\phi]_\times=
\begin{bmatrix}0&-\phi_z&\phi_y\\
\phi_z&0&-\phi_x\\
-\phi_y&\phi_x&0\end{bmatrix}.$$

若 $\boldsymbol\phi=\theta\mathbf s$，$\|\mathbf s\|=1$，那么 $\mathbf s$ 是等效旋转轴，$\theta$ 是等效转角，且

$$\Delta R=\exp([\boldsymbol\phi_S]_\times),\qquad
\boldsymbol\phi_S=\operatorname{Log}(\Delta R)^\vee.$$

这里 `Log` 是矩阵对数，$\vee$ 是帽算子的逆运算。因为 $B$ 是旋转矩阵，

$$B[\boldsymbol\phi_S]_\times B^{-1}=[B\boldsymbol\phi_S]_\times,$$

于是

$$\begin{aligned}
Q&=B\exp([\boldsymbol\phi_S]_\times)B^{-1}\\
 &=\exp\!\left([B\boldsymbol\phi_S]_\times\right),\\
\boxed{\boldsymbol\phi_M&=B\boldsymbol\phi_S,
\quad \mathbf s_M=B\mathbf s_S,
\quad \theta_M=\theta_S.}
\end{aligned}$$

严格区分术语：$Q=B\Delta R B^{-1}$ 是**李群元素的共轭**；$\mathrm{Ad}_B(\boldsymbol\phi_S)=B\boldsymbol\phi_S$ 是 **SO(3) 对李代数的伴随作用**。它们通过指数映射相容，$B\exp(\hat\phi)B^{-1}=\exp(\widehat{\mathrm{Ad}_B\phi})$。因此“先换基旋转矩阵”与“先映射旋转轴，再用 Rodrigues 公式重建矩阵”在数学上等价。

Rodrigues 公式写为

$$\exp([\mathbf s]_\times\theta)
=I+\sin\theta[\mathbf s]_\times
 +(1-\cos\theta)[\mathbf s]_\times^2.$$

GUI 驱动直接使用矩阵共轭，减少来回转换；[旋转向量 demo](../so3_rotvec_demo.py)才计算 $\log Q$，用箭头把 $\boldsymbol\phi_M$ 画在三维向量空间里。

## 6. 模型原本不在单位姿势时，乘法应放哪侧

手腕 demo 的模型归零姿态在自己的局部坐标中为 $I$，因此直接用 $Q$ 绘制。如果模型在世界坐标中原本已有姿态 $R_{WM,0}$，而 $Q$ 仍表达在模型**初始局部轴**中，则

$$R_{WM,t}=R_{WM,0}\,Q.$$

若要写成左乘，必须先把旋转转到世界坐标：

$$Q_W=R_{WM,0}Q R_{WM,0}^{-1},\qquad
R_{WM,t}=Q_W R_{WM,0}.$$

两种写法完全一致。不能只说“旋转矩阵左乘模型姿态”，却不说明旋转轴是在哪个坐标系里表达的。

对于人体树状模型，一个部位还有父部位姿态。当前实现先求子部位的模型系绝对方向，再以 $R_{\rm parent}^{-1}R_{\rm child}$ 得到关节局部旋转，最后按骨架层级组合；这与单独固定前臂的手腕 demo 不完全相同。

## 7. “李代数向量连续”需要加一个边界条件

一段平滑的物理运动给出连续的 $R(t)\in SO(3)$，但**不能保证全程使用唯一、连续的主值旋转向量**。常用主值对数规定 $\theta\in[0,\pi]$。绕固定轴转到 181° 时，同一姿态也可表成绕反向轴转 179°；主值旋转向量会在 180° 边界跳到球的另一侧。转完整 360° 后 $R=I$，主值旋转向量又是零。

这不是设备突然反转，而是 $SO(3)$ 的拓扑性质及对数映射分支选择。沿着一段具体轨迹可做时间上的展开（例如跟踪四元数符号、累计角增量），但那得到的是**依赖运动历史的展开结果**，不能仅由某一时刻的 $R(t)$ 唯一恢复。旋转向量的模长也不是角速度：前者是从零位到当前的有限转角，角速度还需要时间微分。

因此 [旋转向量 demo](../so3_rotvec_demo.py)刻意画出主值向量及其端点轨迹，并标出 180° 球面；跨边界时箭头跳变，而右侧的旋转矩阵仍代表连续姿态。接近 0° 时轴方向没有唯一意义；接近 180° 时轴的符号也容易受噪声影响。

## 8. 对照一遍完整数据流

设点击 GUI 归零时采到 $R_0$，当前采到 $R_1$，轴映射为 $B$。程序执行：

1. 每包 R/P/Y 按 ZYX 约定构造 $R_0,R_1\in SO(3)$。
2. 计算设备中立轴下的相对转动 $\Delta R=R_0^\mathsf T R_1$。
3. 换到模型轴下：$Q=B\Delta R B^\mathsf T$。
4. 将 $Q$ 应用于手掌及其彩色模型轴，手腕转轴原点保持固定。
5. 若要理解“绕哪根轴转了多少”，再算 $\boldsymbol\phi_M=\operatorname{Log}(Q)^\vee$ 并绘制它；不是用它推算平移位置。

最简代码对应为：

```python
R0 = rotation_matrix(roll0, pitch0, yaw0)
R1 = rotation_matrix(roll1, pitch1, yaw1)
delta_sensor = R0.T @ R1
Q = B @ delta_sensor @ B.T
rotvec_model = rotation_vector(Q)  # 三个分量，单位 rad；仅在需要显示轴角时计算
```

对模型控制而言，最重要的是每次都以同一个 $R_0$ 和同一个轴映射 $B$ 解释后续数据；更换绑带位置、改设备融合／安装参数或重新定义真实中立姿势后，应重新确认这两者。
