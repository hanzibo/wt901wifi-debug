## 2. 保持不变的规则

- 控件标题、排列、启动入口与窗口方法签名不变；15 部件与轴坐标保持原定义。
- 保存失败不改设备绑定；录制/穿戴窗口期间的姿态模式切换禁令保持。
- 断流恢复超过 5 秒才按原规则失效穿戴标定，恰好 5 秒不改变判定。
- 显示归零不覆盖穿戴标准参考；自然掌面和 RGB-D 链路不改动。
- 单部位静止段少于 30 包仍取消；双臂某一设备断流不等于全部参与设备断流。
- λ 在开始采集时冻结，本轮拟合使用该快照；取消/完成后解锁。
- 双臂应用仍先检查全部候选；质量提醒须确认，不能悄悄部分应用。
- “恢复手动映射”仍是停用所选部位穿戴标定，不是重新应用某份历史报告。
- 关闭正在采样的窗口会取消本轮、关闭记录器，不重复占用 UDP。

## 4. 手动验收（建议 10–15 分钟）

沿用已有启动命令、设备安装和配置，只做人体/仿真预览。
先停止机器人随动，不要连接真实机器人执行硬件命令。

### A. 主窗口、人体视图和入口

1. 启动普通人体窗口或平时使用的融合窗口。右侧所有原按钮、15 部位分配项应在。
2. 转动人体视角，使用 R 重置视角、A 切换坐标轴；人体随动和轴位置应正常。
3. 打开/关闭弱先验参数、穿戴标定、双臂标定、自然掌面、新机器人/X1、双手 IMU 配置。
   只检查实际使用的入口；关闭再打开，不应出现空窗口、重复实例或报错。

### B. 设备分配与算法

1. 刷新在线设备，给一个未分配部位选设备，再解除分配；检查列表与状态刷新。
2. 打开轴映射，先取消一次，原映射不变；再确认一个已知正确映射，显示应更新。
   不要为测试给已标定部位随意设置错误映射，否则按原规则会失效标定。
3. 非录制状态切换一个部位的厂商姿态/陀螺+加计；检查选择和人体输出。
4. 录制中尝试换模式，应提示禁止并恢复原选择。关闭穿戴窗口后才允许换模式。

### C. 单部位穿戴流程

1. 用已正确安装且在线的一台上臂或前臂设备，完成单部位动作采集。
2. 开始前将 λ 设为 0 或 0.15；开始后控件被冻结，结束/取消后可再次修改。
3. 检查准备→保持静止→下一动作的提示、蜂鸣、包数以及最终通过/需重录结果。
4. 查看回放，应用通过结果，确认人体随动；恢复该部位手动映射，检查状态反馈。
5. 再开始一轮，在准备阶段取消；立即重新开始后关闭窗口，应正常取消，无遗留录制。
6. 若平时使用躯干或手背单部位标定，补测相应流程；无设备的项目可明确记为未测。

### D. 双臂穿戴流程

1. 用当前在线且绑定的上臂/前臂设备完成一轮联合穿戴标定；允许部分设备先行。
2. 下拉列表应保留各参与部位及各自结果；回放、误差和质量提醒可正常查看。
3. 如出现质量提醒，先取消应用，结果不得应用；确认后才应用全部合格结果。
4. 恢复一个部位的手动映射，其余已应用部位应保留；结果下拉和按钮状态更新。
5. 重新开始/取消一次，确认按钮恢复；并不是要求故意做差动作制造失败。

### E. 融合与下游快速回归

1. 在相机/一体标定窗口完成一轮并应用；三维观测、冻结/恢复与原人物确认仍可用。
2. 快速检查机器人双臂、手掌跟随以及左右手指开合，停止行为保持。
3. 正常关闭程序，再启动，设备分配/映射仍按配置读取。
   临时穿戴标定不是因此自动持久化，仍遵循已有标定恢复流程。
