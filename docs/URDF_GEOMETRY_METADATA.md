# URDF 可获取的机器人几何与运动学元数据

本文说明仅通过 URDF 能读取、推导什么，以及不能确认什么。以当前 X1 模型为例，数学约定与 [URDF 变换链与 PoE 等价推导](URDF_POE_EQUIVALENCE.md) 一致。

## 1. 三个信息层级

| 层级 | 例子 | 是否需要额外文件或测量 |
| --- | --- | --- |
| URDF 直接声明 | 父子关系、joint origin、axis、基本几何尺寸 | 不需要外部网格 |
| 从声明推导 | 零位构型、空间/体系螺旋轴、FK、雅可比 | 需要计算，不需要 STL |
| 外部资源或实物事实 | 网格顶点、真实尺寸误差、编码器零偏 | 需要网格文件、厂商资料或实测 |

URDF 描述的是一个机器人模型，不是机器人实物的自动测量报告。

## 2. 连杆、关节与拓扑

从 `link` 和 `joint` 可读取：

- 连杆名、关节名。
- 关节的父连杆和子连杆。
- 关节类型：`fixed`、`revolute`、`continuous`、`prismatic` 等。
- 从所选基连杆到某末端的唯一路径（有效的树形模型下）。

当前左臂路径是：

```text
base_link_0 → joint1 → L1 → joint2 → L2 → joint3 → L3
            → joint4 → L4 → joint5 → L5 → joint6 → L6
```

右臂对应关节 51～56、连杆 R51～R56。名称本身不提供“上臂”“肘”“手腕”的解剖学语义；本项目人为选择 L4/R54 原点作为肘参考点，L6/R56 原点作为腕/末端参考点。

具有 `mimic` 关系的关节也不一定是独立自由度。关节数量不能直接等同于可独立控制的自由度数量。

## 3. 关节零角位置与朝向

关节的 `origin xyz/rpy` 定义关节参考系 $J_i$ 相对于父连杆系 $L_{i-1}$ 的固定变换：

$$
O_i={}^{L_{i-1}}T_{J_i}
=\begin{bmatrix}R_{O_i}&p_{O_i}\\0&1\end{bmatrix}.
$$

标准单位是：位置米，角度弧度。`rpy` 对应固定轴 roll、pitch、yaw，旋转矩阵为

$$
R_{O_i}=R_z(\mathrm{yaw})R_y(\mathrm{pitch})R_x(\mathrm{roll}).
$$

在关节变量为零时，子连杆系与关节参考系重合，因此

$$
{}^{L_{i-1}}T_{L_i}(0)=O_i.
$$

“零角”不意味着 $O_i=I$，也不意味着连杆轴方向相同或原点重合。它是模型的零配置，不保证等于编码器原始读数为零时的实物配置。

## 4. 关节轴和轴线

`axis xyz` 给出关节参考系 $J_i$ 中的轴方向。对旋转/移动关节，使用归一化方向 $a_i$；无效的零向量不能用于运动学。

对普通单轴旋转关节，绕轴本身转动不改变该轴，所以 $a_i$ 在子连杆系中的数值与在 $J_i$ 中相同。但定义上它是关节系表达，不能直接当作父系或基系表达。

设零位累计变换为

$$
G_i=O_1\cdots O_i=\begin{bmatrix}R_i^0&p_i^0\\0&1\end{bmatrix}.
$$

则旋转关节轴在基系中的零位方向及轴线上一点为

$$
\omega_i=R_i^0a_i,\qquad r_i=p_i^0.
$$

由此得到整条轴线 $r_i+\lambda\omega_i$。轴上一点不唯一，沿轴平移该点不改变轴线或螺旋轴。

采用旋量排列 $[\omega;v]$，旋转关节的空间单位速度旋量为

$$
\mathcal S_i=\begin{bmatrix}\omega_i\\-\omega_i\times r_i\end{bmatrix}.
$$

移动关节则为

$$
\mathcal S_i=\begin{bmatrix}0\\R_i^0a_i\end{bmatrix},
$$

其关节变量单位是米。固定关节没有独立关节变量，但固定 origin 必须纳入累计变换。

## 5. 由以上信息可以推导什么？

不读取 STL，就能建立：

1. 所有连杆的零位变换 $M_k=G_k$。
2. 每个关节的零位空间轴线和空间旋量 $\mathcal S_i$。
3. 指定末端 $M$ 后的体系旋量 $\mathcal B_i=\operatorname{Ad}_{M^{-1}}\mathcal S_i$。
4. 任意有效关节配置下的 FK 与 link TF。
5. 空间/体系雅可比、选定点的速度雅可比。
6. 模型中的参考点间距离，以及它们随关节角变化的规律。

第 6 项不等于“自动得到人体式骨长”。一个刚性 link 内两点距离固定，但跨越多个活动关节的两个参考点距离可能变化。

多自由度 floating/planar 关节需要对应的多自由度参数化；不能无条件套用每个 joint 一个标量 $q_i$ 的单轴公式。当前 X1 双臂实现针对旋转关节链。

## 6. 显示几何和碰撞几何

`visual` 与 `collision` 可分别包含：

| 元数据 | 含义 |
| --- | --- |
| `origin` | 几何参考系相对于所属 link 的局部变换 |
| `box size` | 长方体三边长度 |
| `cylinder radius/length` | 圆柱半径和长度 |
| `sphere radius` | 球半径 |
| `mesh filename/scale` | 网格资源路径及三轴缩放 |
| 材质颜色、透明度、纹理引用 | 显示外观；渲染器支持可能不同 |

**URDF 引用 STL/DAE 时，不在 XML 内存储其三角面片。**网格顶点、精确外形、包围盒等需要加载资源文件，并应用 scale 和 visual/collision origin 后计算。

关节原点、link 原点、visual 原点、网格中心和质心可以不同。网格看起来居中，不意味着 link 原点就在几何中心。碰撞几何也可以是简化体，不能等同于显示网格。

## 7. 质量与惯性：可选、非 FK 必需

`inertial` 可提供质量、质心位置、惯性参考系朝向和惯性张量六个独立分量。惯性张量须与其声明的参考系一起解释，不能把该矩阵直接当作基系中的惯性。

这些数据主要用于动力学，不是当前 FK/IK 必需。是否真实准确、是否正定合理，需要另行检验；URDF 字段存在不是准确性的证明。

## 8. 关节限制与非几何扩展

可能存在的位置上下限、速度、力/力矩限制，以及 damping、friction、mimic 关系。旋转位置限位用弧度，移动位置限位用米。

`continuous` 不声明位置上下限。它表示模型采用连续旋转关节，**不证明实体关节、线缆和驱动器允许无限旋转**。X1 预览软件限位也不是硬件安全限位。

传动、`ros2_control`、Gazebo 等扩展可描述接口或插件配置，但仅存在这些字段不代表对应驱动、仿真或控制链已经可用。URDF 通常不包含完整通信协议。

## 9. 不能仅靠 URDF 确认的信息

- 实物装配误差、真实轴线偏差、编码器零偏。
- 控制器读数与 URDF 正角方向是否一致。
- 真实硬件安全限位、碰撞风险、力矩能力的充分验证。
- 未显式定义的 TCP 或夹爪尖端参考系。
- IMU 安装姿态及设备到身体/机器人部位的标定关系。
- 人体骨段与机器人 link 的对应关系。
- 网格资源的真实内容与长度单位是否正确。

这里“不能确认”不是说不能把这些信息显式编码进模型或扩展，而是不能从未声明的信息、命名或外观中自动推断。
