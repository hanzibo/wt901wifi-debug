# 真机左臂六轴 IMU 随动（实验）

从人体主窗口打开“真机受限 IMU 控制…（单肘 / 左臂六轴）”。默认仍是原单肘 L4 模式。
六轴模式需要左上臂、左前臂、左手背三个不同的在线设备，并完成自然下垂归零。
上臂和前臂需要穿戴标定，或明确勾选手动轴映射。手背输入不可缺省。

## 模型与目标

- 使用既有 CoppeliaSim 场景导出的名义螺旋轴和掌部坐标；无需运行 CoppeliaSim。
- 导出姿态是运动学几何的参考，不改写成零位。FK 用 `q - reference` 正确还原任意场景角度。
- 采集人体三段参考姿态，将其对应到当前人工确认的机器人指令起点，而不是下垂的场景中立位。
  因此人体不必摆成机器人上电姿态。再次接管保持上次最后指令，不自动回零。
- 肘、腕位置采用骨段位移增量，按机器人 / 人体骨段长度分别缩放；臂段朝向作为软约束。
- 阶段一求 L1–L4，不加入手掌朝向残差；阶段二只求 L5–L6 的掌向残差。
  不追加旧的固定 90° 掌向偏置，因为此模式直接以接管机器人掌向为锚点。
- 候选映射为 `协议角 = 90° + sign × 场景角(度)`。原源码给出 `+90°` 映射，
  但新增各轴的真机方向、范围和模型准确性尚未逐轴物理验证，必须先小幅验证。
- 全六轴目标用于比较。部分输出时，其余轴保持接管角，不能认为机器人满足全部 IK 目标。

## 输出与限制

六轴默认全部勾选（按用户指定配置），但连接不发送，仍须上电确认、安全许可和明确启动。
首次验证请主动取消其他轴，至少保留一轴才能采集并启动。首帧逐字节保持确认起点。
右臂、头、腰始终 90°，全部手指量始终 0；未勾选左轴保持接管时的指令值。
每帧检查未授权通道字节。所有这些显示均是**指令值，不是测量角**。

默认发送 20 Hz，每轴速度 100°/s、加速度 150°/s²。每轴可自定义至 250，
该上限不是验证过的安全值。默认范围为 L1 0–226°、L2 90–233°、L3 0–180°、
L4 0–119°、L5 0–180°、L6 51–122°，方向全部 +1。
用户可收紧或在原 PC 软件范围内扩大；这些范围不是机械限位、碰撞检测或安全认证。

串口线程独立执行六条加速度受限轨迹，各轴不做时间同步，避免慢轴强制拖慢快轴。
IK 在另一线程运行，只保留最新输入，不排队追赶旧姿态；IK 完成后再次检查原输入有效期。
输入年龄上限仍是 250 ms，不会以 IK 完成时刻刷新旧数据。
短暂输入过期先减速等待，额外 250 ms 内有效新解可平滑恢复；超过窗口则锁定暂停。
标定 / 设备 / 映射变化、求解异常、取消安全许可仍触发不可自动恢复的指令侧制动。
详见 [两级断流保护](REAL_ROBOT_SHARED_TELEOP.md#短暂断流容忍真机各-imu-模式)。
日志错误同样触发制动。串口部分写入后停止，不重试，重新上电确认起点。
关窗 / Esc / 主窗口退出均先请求制动并等待发送线程退出。

## 手动验收顺序（必须在场看护，独立物理断电可用）

1. 不接真机先打开窗口，确认原 L4 模式保留；切换六轴检查配置并主动取消暂不测试的轴。
2. 真机重新上电，保持已验证的全部 90° / 手指 0 起始姿态。明确选择 CP2102 串口，
   点击连接（不发送），人工确认起点。禁止同时打开旧手动发送 demo。
3. 分配并启用三个左侧 IMU、归零、穿戴标定或手动轴映射。保持当前任意安全人体姿态，
   勾选安全确认，**先仅许可 L4**，稳定保持 0.5 秒、采集参考，然后明确启动。
   检查启动无跳变、其他关节不动、L4 小幅慢动作可跟随。
4. 减速暂停，确认停止；新一轮采集前保持稳定。依次独立验证 L1、L2、L3、L5、L6，
   新轴先主动调低为 10/20 及小范围。核对旋转方向，若错误暂停后调整 ±1，重新采集。
   任何异常立刻按实际情况物理断电，不能依靠软件暂停作为急停。
5. 逐轴确认后才尝试组合轴和完整左臂；不要直接把全部轴设为 250。
   L5/L6 屈腕试验时人体肩肘保持静止，观察肩肘指令是否保持稳定。
6. 暂停 / 取消安全许可 / IMU 断流 / Esc / 关闭主窗口各测试一次；应减速暂停、不自动续发。
   对暂停后的重新采集接管检查：第一帧不跳回 90°。
7. 单肘模式只能接受其他角度均 90° 的起点。六轴已经改变其他关节后，
   不可直接切换单肘继续发送；重新上电并重新连接确认。不会暗中把其他关节复位。

## 日志

`OptUSBProj-ubuntu/recordings/real_robot_imu/<时间-ID>/control.jsonl`

包含 `arm_reference`、`arm_model`、`arm_ik`、`engage`、`write`、`paused`、`error`。
新增 `arm_start_attempt`、`arm_start_rejected`、`arm_start_accepted`：同一次尝试用 `attempt` 关联，
记录三段各自相对参考的朝向差、输入年龄 / 剩余有效期、设备年龄快照、签名匹配及输出许可。
拒绝原因单独区分姿态变化、输入过期、缺少样本、设备签名变化、安全许可和初始化异常；
原 2° / 250 ms 保护阈值不变。启动按钮下方会显示具体结果和三段角度差。
`arm_start_gate` 仅在按钮许可条件变化时记录，解释按钮为何未启用；
`arm_reference_invalidated`、`arm_input_invalid`、`arm_input_recovered` 补充参考失效及输入中断 / 恢复事件。
`arm_ik` 提供六轴目标、名义位置 / 朝向残差、IK 时间及原输入到期时间；
`write` 提供完整 54 字节、每轴指令速度 / 加速度、许可掩码、输入年龄、发送间隔 / 写入耗时。
TXD/GND 没有反馈，日志不能证明机器人实际角度、执行时序、动态滞后或物理制动效果。

自动化测试只使用离线数学、Qt offscreen 和伪终端串口，不驱动任何真实设备。
