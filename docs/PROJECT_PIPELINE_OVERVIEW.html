B

航向反馈如何闭合

  1. 用同步 IMU 姿态预测骨段指向。
  2. 与相机观测的水平投影比较。
  3. 计算绕相机重力轴的剩余角差。
  4. 低通、限速更新累计补偿。
  5. 换回 IMU 固定参考系，左乘姿态。
数学步骤 表示
预测方向 d_C = Q R b_S
相机系补偿 H_C = Exp(k_C δ)
共轭换基 H_W = Q^T H_C Q
融合输出 R_f = H_W R

Exp(v) 表示旋转向量的指数映射。 ^T 表示转置。相机不改写纯 IMU 积分器。

C

一次动作，两路独立标定

标定 求出的固定量 用途
穿戴 B、配对中立矩阵 N 设备运动映射到人体模型
相机 Q、骨轴 b_S、骨长中值 预测视觉方向与异常筛选

两路不会共用一个 B。 穿戴合格不代表相机标定合格。 重复动作不参加拟合，用于独立验收。

D

参考系与换基，不要混用

坐标系 含义 关键关系
S 随设备运动的本体系 R 把 S 向量变换到 W
W 软件固定参考系 Z 不保证竖直，保存 k_W
C 相机坐标系 Q 把 W 向量变换到 C
M 人体模型参考系 X 前、Y 左、Z 上
F 穿戴拟合的竖直参考系 A k_W = e_Z

重力滤波保留 W，并约束 R^T k_W。 穿戴拟合使用 A R；A 是固定换基。 相机拟合直接使用 R，并要求 Q k_W = k_C。

模式 姿态来源 航向信息

归零保存同模式姿态 N。 人体旋转采用 B (N^T R_f) B^T。 父子相对旋转与固定骨长组合成骨架。 软件归零不等于设备寄存器清零。

H

已知边界与保护

方向一致不等于真值准确

视觉深度来自皮肤或衣服表面，不是骨关节中心。 单根骨段方向不能独立确定绕长轴的解剖学扭转。 站直肩髋方向只是相机重力方向的近似。

情况 系统处理或限制
骨段近竖直 航向不可观测，冻结更新
关键点或深度失效 保留已有补偿，IMU 继续传播
时间匹配不合格 拒绝该次视觉更新
累计补偿到达范围 拒绝继续越界；可配置范围
实验性不限累计角度 不解除其他观测与速率门限
相机移动或绑带滑动 停用并重做相关标定
手掌被绑带遮挡 视觉 C0 仍属实验，不是长期纠偏
X1 输出 仅 RViz，不是硬件安全验收
