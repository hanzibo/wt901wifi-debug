# 真机控制参数 Checkpoint

在真机受限 IMU 窗口选择“左臂仿真同源 IK”或“双臂仿真同源 IK”，
点击模式下方的“参数 Checkpoint…”按钮。

## 保存 / 对比 / 加载

1. “从当前界面新建”：复制当前模式的数值。填写名称、备注，在编辑表内修改。
2. “保存修改”：写入本地预设，**不修改主窗口，不发送指令**。
3. “另存为”：创建新的预设 ID，保留原方案，方便对比实验。
4. 左侧选择已有预设。右侧显示其内容，尚不会加载到主窗口。
5. 点击“加载到当前界面”，展开差异详情，确认后覆盖数值。
6. 加载后重新核对逐轴输出勾选、重新确认安全和 T 型参考，再采集目标、明确启动。

未保存编辑不能直接加载；选择其他预设或关闭时会询问是否放弃修改。
主窗口显示最近加载的名称；手动改变包含在预设中的数值时显示“已修改”。
不会启动时自动加载，不会自动保存主窗口改动。

## 范围与安全边界

- 左臂模式：L1–L6 的最小角、最大角、速度、加速度。
- 双臂模式：R1–R6、L1–L6 的四项数值。
- 保存停止姿态类型（二选一）：侧举只配置每侧2、4关节；前举只配置每侧1、2、4关节。
  仅保存所选姿态的参考协议角和容差；不会同时启用两种检测。
- 两种模式均保存停止信号开关和持续时间（0.1–120 秒，默认 7 秒）。
- 保存每侧回位顺序（1–6 各一次）、回位速度 / 加速度（0.1–250）、步间停留（0–10 秒）。
- 保存同源接管的过渡姿态容差（0.1–30°，默认 2°）、启动倒计时（1–120 秒，默认 10 秒）、
  指令完成后等待（0–30 秒，默认 2 秒）。等待不是真机到位反馈。
- 不包含发送频率、协议方向、手掌固定转向、镜像开关、双臂先后或逐步人工确认开关。
- 不包含设备标定、中立位、接管目标、实际位置或运动进度。
- 不保存自动启动授权；每次倒计时接管都须二次确认，加载不会启动。
- 不恢复逐轴输出许可；保留主窗口原勾选。加载后安全许可会清除，停止信号开关按预设恢复，
  停止姿态参考确认会撤销，旧接管参考 / 输入历史会清除。
- 随动、减速、短断流等待、IK 运行、回位或回位等待人工确认时均禁止加载。
  倒计时及自动接管期间同样禁止加载。
  串口可保持已连接但空闲；加载入口不会发出运动指令。
- 格式错误、缺少关节、模式不符、非有限值、范围反转、超软件包络均拒绝加载，
  主窗口保持原值。停止姿态参考角必须落在预设的对应关节范围内，容差为 0.1–30°。
- 数值最多两位小数；不通过控件截断或取整来“修复”非法值。

**这些只是实验参数，不是机械限位认证、碰撞保护或实际到位证明。**
比较实验时还应核对未保存的方向、频率、掌向设置及人体标定。

## 文件位置与格式

默认位置相对于项目根目录：

```text
OptUSBProj-ubuntu/config/real_robot_checkpoints/
  left_shared_ik/<UUID>.json
  bilateral_shared_ik/<UUID>.json
  trash/<模式>/<原 UUID>-<回收 UUID>.json
```

目录已加入 Git 忽略；重启程序后文件仍保留。两种模式不能跨模式直接加载。
名称和备注写在 JSON 内，不用用户名称构造文件路径。

当前版本 4 包含这些字段：

| 字段 | 含义 |
| --- | --- |
| schema_version | 整数 4 |
| mode | left_shared_ik 或 bilateral_shared_ik |
| id | 与文件名一致的 UUID |
| name / notes | 名称（不超过 80 字符）/ 备注（不超过 2000 字符） |
| created_at / updated_at | 含时区的 ISO 时间戳 |
| joints | 以 L1 / R1 等关节名为键；每项含 lower / upper / speed / acceleration |
| gesture | 仅所选姿态的检测轴名；每项含 angle / tolerance |
| stop_signal | enabled 布尔值、seconds 持续秒数、kind 姿态类型 |
| return_settings | order 六轴整数列表、speed、acceleration、dwell |
| start_settings | tolerance 过渡容差、countdown 倒计时、settle 指令完成后等待 |

旧版 1 文件可直接加载：新增项默认关闭停止信号、持续 7 秒、顺序 1,3,5,6,4,2、
速度 10°/s、加速度 20°/s²、停留 0.5 秒。旧版 1 / 2 的接管参数补为上述默认值。
旧版 1–3 的姿态均解释为侧举（`lateral_raise`），保留原角度与容差。
前举类型为 `front_raise`。读取不会修改旧文件；主动保存后升级为版本 4。

保存使用同目录临时文件、fsync 和原子替换。保存前检测同一预设是否已由另一窗口修改。
损坏文件在管理窗口提示并跳过，不影响其他预设。删除需要确认，文件移入 trash，
不是永久删除；恢复时可把文件改回其 JSON 内 id 对应的 `<UUID>.json`，移回对应模式目录。
当前已加载的数值不因删除预设而改变。

加载时若已有本次日志，会写入 `checkpoint_loaded`，包含 ID、名称及完整预设数值。
用于复核加载行为，不代表实际运行参数或实体角度反馈。

## 手动验收

1. 先不连接真机串口，保存一个左臂预设 A；修改速度和 T 型角，另存为 B。
2. 先后加载 A / B，核对所有数值；检查取消加载时主窗口不变。
3. 切换双臂模式，新建 C。确认列表不含 A / B，左右臂和四个 T 型值都能恢复。
4. 关闭窗口后重新打开，确认预设仍在；手动改一项应显示“已修改”。
5. 加载后核对输出勾选保持、安全勾选清除，停止开关和时间恢复，但 T 型参考需重新确认。
   在预设内修改四项回位参数，另存后加载，确认主窗口一致；保存本身不改变主窗口。
   将持续时间设为不同值，低速测试不足该时间不触发、离开容差重新计时、达到该时间暂停。
6. 在已有独立断电手段的条件下，仅勾选小范围低速 L4，按原流程测试接管。
   随动 / 断流等待 / 回位期间 Checkpoint 按钮应禁用。
7. 分别保存侧举 / 前举预设，互相加载，确认姿态选择、检测轴及各参考角 / 容差恢复一致。
   前举左臂应有3个检测轴，双臂应有6个；切换侧举后第1关节不参与检测，旧参考须重新确认。
