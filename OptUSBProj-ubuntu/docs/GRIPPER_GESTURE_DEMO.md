# 双 IMU 夹爪手势观察 demo

此程序只观察，不发送夹爪或机器人命令，不写设备寄存器。
支持拇指与四指绑法比较；设备自动发现，角色由用户选择，没有硬编码设备 ID。

实测限制：用户观察到两设备不动时闭合角仍持续增大，差分航向漂移使这条路线不适合当前长期夹爪控制。保留为实验与对照工具；当前可用替代方案为 [手机局域网页面输入](LAN_GRIPPER_DEMO.md)。

## 启动

先关闭占用 UDP 1399 的人体／手腕 GUI，保持两台 WT901 连接电脑热点：

```bash
cd /home/hzb/Work/WT901
conda run --no-capture-output -n OptUSBProj-yolo python -u OptUSBProj-ubuntu/gripper_gesture_demo.py
```

无设备界面测试使用 `--demo`，合成数据不打开 UDP，也不代表真实性能。
监听地址／端口可用 `--listen-ip`、`--listen-port` 修改。
复用本机现有 NumPy、SciPy、PySide6；曲线用原生Qt绘制，无新增依赖。

## 操作

1. 两设备上线后在列表中选择手背及拇指／四指设备，不能选同一台；不自动决定角色。
2. 默认使用现有陀螺＋加计滤波器，支撑手等待两设备静止学习完成。可切换厂商 RPY 作对照，切换会清除手势参考。
3. 开手时尽量让两设备外壳 XYZ 轴同向。否则选择指段设备三轴在手背设备系中的近似映射；不要把 GUI 人体系的轴映射当成这里的映射。
4. 点击采集开手参考；默认准备3秒、静止采样1.5秒，可调。再采集舒适闭合参考，未必为90°。
5. 观察有符号手势角、离轴残差、原始闭合比例和平滑进度条；展开为0，闭合为1。
   默认残差超过20°停止更新平滑闭合量。勾选“实验：离轴残差仅提示，不阻止更新”后仍更新，但保留告警、曲线和诊断；切换此选项无需重新采集参考。它不会绕过数据过期、同期插值或170°旋转分支检查，也不解决绑带滑动／漂移问题。
6. 保持指型，抬臂和整体转腕；再固定手背重复开合、保持半握，比较两种绑法的串扰和重复性。
7. 点击轻量记录按钮。记录路径显示在按钮中，停止后状态区显示路径。将目录提供给分析者即可。

改绑、换模式／映射、设备接收间隔超过0.5秒或明显片内时钟跳变会清除参考，需重采。数据龄超过0.3秒或同期插值间隔超过0.1秒暂停估计，进度条保持最后值，状态区明确告警。端点窗口至少10组不同时间样本，两设备各自SO(3)均值的角差P90须不超过3°。这不是临床或真机安全标准。

## 数学与假设

开手样本为 N_H、N_F，安装映射 K 表示开手指段设备系到手背设备系。计算

`T = (N_H.T R_H).T K (N_F.T R_F) K.T`。

这样允许两个软件参考系初始不同。但 K 必须近似正确；单纯开手采样不能识别任意连续安装关系。当前提供24种正交右手轴映射，不是完整的功能轴／参考对齐自动标定。

闭合样本 `v_close = Log(T_close)∨` 定义主手势轴 `a = v_close / ||v_close||`。实时 `v = Log(T)∨`，有符号手势角为 `theta = a.T v`，离轴残差为 `||v-theta*a||`。闭合量为 `clip(theta / ||v_close||, 0, 1)`。

开合幅度小于10°拒绝闭合标定；相对旋转达到170°拒绝估计，避免180°对数分支。闭合量使用0.12秒时间常数低通。离轴残差超过20°保持平滑显示并提示，原始诊断仍保存；残差并非准确率或漂移检测的充分条件，沿主轴漂移也可能残差很小。

姿态积分使用设备片内时间；两设备间按电脑接收单调时间取共同最新时刻，另一条序列以SO(3) SLERP插值，不外推。这只是接收时间对齐，没有跨设备硬件时钟同步，网络延迟差仍可能引入误差。

本版为端点手势投影，不是假设拇指所有动作均为一维铰链。不直接相减欧拉角，不自动消除差分航向漂移，不用相机纠偏，不改现有人体或X1程序。

## 记录内容

默认保存至 `OptUSBProj-ubuntu/recordings/imu_gripper/时间-编号/diagnostics.jsonl`，受现有 Git 忽略规则保护。

- `session`：角色ID、模式、绑法标签、安装映射、当前端点标定及是否合成数据。
- `imu`：收到的原始包、接收单调时间、当前姿态矩阵、参考epoch。
- `calibration` / `reference_cleared`：标定／失效事件。
- `gesture`：共同采样时刻、角度、残差、闭合量和平滑显示值及离轴有效标记。
- `residual_policy`：记录开始及切换时的残差策略；`gesture.valid`仍表示残差是否合格，`residual_warn_only`与`update_allowed`另行记录是否允许超限更新。

记录没有图像，包含设备标识和动作数据；不自动上传。尚未接入RViz关节57／7，也没有真实夹紧力、触觉、接触检测或真机失效策略。
