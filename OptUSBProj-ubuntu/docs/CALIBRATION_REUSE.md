# 历史标定保存与快速恢复

适用于设备持续佩戴、绑带未滑动、设备未换位、相机固定的调试场景。支持左右上臂、左右前臂，可保存四部位或当前具备完整标定的部分部位。不是免验证的一键恢复，也不是长轴扭转的视觉标定。

## 首次保存

在 RGB-D GUI 完成并应用穿戴标定和相机标定后，停止 X1 随动、录制及其他标定窗口。点击 **历史标定 · 保存 / 快速恢复 → 保存当前已应用标定**。

只保存同时具有连续穿戴映射、有效相机绑定、匹配设备 ID 和参考系的部位。文件位于 `OptUSBProj-ubuntu/calibrations/reusable/profile-时间-随机码.json`，包含安装映射、设备骨轴、骨长、中立位模型到相机的方向关系、相机硬件/内参和视觉模型签名。建议在标定刚完成、中立位仍符合当时约定时保存。

不保存可直接恢复的旧积分姿态、陀螺零偏、旧中立矩阵或累计补偿角；不自动持久化“不限累计角度”开关。

## 已有历史记录

- **配置 / 相机报告…**：可选择上述配置，也可选择历史相机分析的 `report.json`。报告必须是 `live_runtime_pose`，其 `source_session` 原录制仍需保留 `manifest.json`、`runtime_pose.jsonl`、`camera_calibration.json`，且其中已保存当时应用的连续穿戴映射。导入会检查报告与原录制会话及设备参考系匹配，再转换为便携配置；不会应用旧 Q。
- **导入历史联合录制…**：选择同时记录了已应用穿戴和相机标定快照的联合录制目录。单纯用于拟合相机的动作录制通常尚未应用本轮相机标定，其 `fusion_at_start` 可能为空；这种情况请使用上一项导入该录制对应的分析报告。
- 缺少匹配的穿戴映射或实时参考系时拒绝导入，不猜测组合不同录制中的矩阵。导入不需要读取视频或原始深度，不修改原录制。

## 下次启动

1. 使用原有 RGB-D 桌面启动项。开启相机、三维观测，选择与历史相同的视觉模型、权重和输入尺寸。
2. 确认部位分配的设备 ID 与历史一致；所有参与部位先选择 **陀螺＋加计**。先停止 X1、其他录制与标定。
3. 打开历史标定窗口并加载配置。检查保存日期、参与部位和来源，勾选安装未移动与中立姿态一致的确认框。
4. 可设置开始倒计时、每步准备时间、参考恢复准备时间和动作采样时间。点击开始后依次执行：
   - 自动复用：默认检查本次实时积分器的 `bias_ready`，已学习设备直接沿用当前零偏，不复制历史文件中的零偏。全部参与设备已学习时，省去整个零偏准备/重估阶段，开始倒计时后直接进入共同中立位准备；部分设备未学习时仅对这些设备寻找安静片段。若后台在准备期间已完成学习，也直接复用。需要排查异常时可勾选“强制重新估计零偏”；此选项与“跳过本次显式零偏重估”互斥。设备在线、设备 ID、积分参考系和相机会话等检查不变，重建积分器后重新判断。学习完成只是曾通过判据，不能当作零偏精度认证。
   - 参考恢复准备（可选零偏重估）：双臂可以支撑，尽量安静，不要故意缓慢转动。程序在整个准备窗口中为每台设备独立寻找至少40帧、跨度至少0.8秒的连续安静片段，而不是只看最后3秒或要求四台同时静止。角速度每帧不超过0.8°/s，加速度模长偏离1g不超过0.08g，相邻重力方向变化不超过1°，断流不超过100ms；仅合格片段更新零偏，不重置积分矩阵。没找到片段时保留当前零偏，显示“未显式重估”或“零偏尚未学习”，继续后续恢复，不伪装成学习成功。可勾选“跳过本次显式零偏重估”；原滤波器的后台自动学习仍运行。此选项不恢复历史零偏、不放宽后续验收门限。未学习零偏时漂移可能更快，遮挡/近竖直姿态的RGB-D纠偏不能保证补偿。
   - 共同中立位：自然下垂，掌心、拇指方向与历史一致，站直并完整入镜。重力参考按原 5° 一致性门限检查，不放宽。
   - 前举、侧举：身体朝向保持不变，肘伸直，动作后静止。仅恢复本次相机对齐，不重拟合历史骨轴或穿戴映射。
   - 再次前举：独立验收，不用于对齐拟合。
   - 回到中立位：验证返回姿态及历史中立系关系。
5. 窗口逐部位显示合格或失败。选择合格部位后，点 **应用所选合格部位**。应用是一个事务，失败回退；不自动打开融合或机器人。
6. 自行把合格部位切换为 **陀螺＋加计＋RGB-D**，先检查人体模型，然后再决定是否启动 X1。

全部参与设备已学习时，默认流程约49秒；存在待学习设备或强制重估时约63秒（含10秒起始倒计时和各步准备）。显式跳过重估也省去该阶段，但未学习设备仍会警告。恢复只保存关键点、同步姿态和分析结果，位于 `calibrations/reusable/runs/recovery-时间-随机码/`，不保存原始彩色/深度图。保存每台设备的复用/待学习/重估/未学习状态及当前零偏，便于审计；不把这些状态当作下次运行可以直接恢复的积分器状态。

关闭/取消窗口不应用穿戴与相机标定；若静止学习阶段已经成功，新的零偏会保留。姿态积分持续运行，不通过“恢复”偷偷归零设备。复用过程中断流、设备分配变化、算法变化、相机或视觉会话变化均停止本轮。

## 数学与验收边界

历史骨段方向 $b_S$ 与安装关系保存不变。当前纯 IMU 姿态记为 $R_{\rm new}(t)$，短动作只拟合一个绕相机重力轴的航向参数：

$$
Q_{\rm new}=\exp([k_C]_\times\psi)Q_g,\qquad
d_C(t)\approx Q_{\rm new}R_{\rm new}(t)b_S.
$$

$Q_g$ 把当前 IMU 重力参考对齐到当前相机中立位肩髋估计的竖直方向；后者依赖站直假设，不是真实地面重力测量。近竖直方向不提供航向约束；前举和侧举须有足够有效水平分量。

历史中立系关系保存为 $C_0=Q_{\rm old}R_{0,\rm old}B^\mathsf{T}$，恢复时检查 $C_{\rm new}=Q_{\rm new}R_{0,\rm new}B^\mathsf{T}$。两者大幅不一致时，不强行将旧映射用到新中立姿态；应核对掌心/拇指、身体朝向、绑带和相机位置，必要时完整标定。

验收保留端点置信度、深度支持、骨长和时间匹配检查，并要求各动作足够采样、前举/侧举方向分离、静止窗口稳定、躯干/肩线方向稳定、重复动作一致、返回中立位一致。得到的新报告绑定当前设备、积分、相机和视觉会话，仍经过既有的实时应用安全检查。

这些是对 RGB-D 观测的**一致性检查，不是真值精度证明**。骨段端点无法完整观测轴向扭转；恢复验证不能保证发现全部绑带滑动。厂商安装模式/量程等参数改变、相机移动、更换设备或重新佩戴后，应重新完整标定，不使用历史恢复。
