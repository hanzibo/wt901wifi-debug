# 视觉辅助穿戴标定：左右双臂与单臂

这是可选实验流程。原来的单部位/双臂 IMU 标定、手动 XYZ 映射及相机航向纠偏均保留。支持左/右上臂、前臂四个部位，窗口可选「双臂联合」「仅左臂」「仅右臂」。只改变用户明确选中的穿戴映射，不自动开启 RGB-D 纠偏、机器人或写设备寄存器。无需新增 Python 依赖。

## 操作

使用原桌面「WT901-RGBD联合采集」，或：

```bash
cd /home/hzb/Work/WT901
conda run --no-capture-output -n OptUSBProj-fusion python -u OptUSBProj-ubuntu/fusion_run.py --camera-source orbbec --rgbd-pose
```

1. 停止 X1 随动；保持相机、设备绑带固定。
2. 将在线 IMU 分配到所选侧的上臂/前臂；双臂联合需四个不同设备。参与部位都选「陀螺＋加计」。手动映射可保留原设置，不要求事先通过原 IMU 标定。
3. 开启三维观测，保证两肩、髋及参与侧的肘腕完整入镜；点击「视觉辅助穿戴标定 · 双臂 / 单臂（实验）」，选择录制范围。四部位均已分配时默认双臂，否则根据已有分配默认单臂；不会静默跳过缺失设备。
4. 设置倒计时、准备和保持时间。自然下垂无需强行贴紧身体，但肘伸直、手腕伸直、手背方向按模型中立位摆好；站直、保持朝向。
5. 执行中立→前举→放下→侧举→再前举→再侧举→回中立→自由验证。双臂联合时同时前平举，再同时向左右两侧平举成T字；保持两肘和手腕伸直。验证时左右臂可分别或同时重复平举、屈肘和轻微转臂；不要移动绑带。
6. 查看中立偏离竖直角、原假设与视觉骨轴差、拟合和独立验证误差。打开双模型回放；下拉框可选择「录制时现有/手动映射」或「同数据原 IMU 平举标定」作为左侧基线。
7. 紫色箭头是视觉骨段方向经过同一中立归一化后的结果，锚点取各模型关节；不是原始相机位置、骨骼真值或轴向扭转观测。
8. 勾选合格部位，确认应用。「通过，但需人工复核」结果须先打开本次双模型回放，检查后再勾选独立的复核确认；程序和应用接口均不会绕过该确认。更新所选部位的 B 与中立位，其他部位不变。可撤销恢复应用前的映射/中立位；若后来重新绑定、积分器重置或手动修改了映射，将拒绝撤销旧状态。
9. 应用后先看人体模型，检查屈肘、共同转臂及前臂轴向运动，再自行启用 X1。新映射只在本次运行中生效。

关闭或切换标定窗口不会自动应用结果。标定流程互斥，录制或分析中不能切换到另一种引导流程；穿戴标定时视觉航向更新冻结，防止反馈参与安装拟合。

## 输出与离线分析

原始数据仍保存在 `recordings/<会话>/`，包含 `camera_guide.json`、`runtime_pose.jsonl`、`vision.jsonl`、`imu.csv` 等。分析保存到独立的 `recordings/analysis_wearing/<会话>-visual-<编号>/`：

- `report.json`：身体参考系、动作窗口、两段拟合、独立验收及警告。
- `right_upper_arm.json` / `right_forearm.json`：可回放预览的候选穿戴映射，包含原始流同步中立姿态。
- 左侧对应 `left_upper_arm.json` / `left_forearm.json`。仅为参与且成功求出矩阵的部位生成文件；失败原因保留在报告中。

新引导记录保存 `capture_scope` 和 `participants`，四台设备共享同一组动作时间窗和相机身体参考系K，但各自估计Q、骨轴b、B及独立中立位；不是四个部位共用一套映射。左右肘伸直分别核验，一侧观测或复测失败不自动判另一侧失败。身体倾斜/转向诊断则是共同的身体条件。

应用可选择全部合格部位或部分部位；失败结果不可勾选，未选部位保持原映射和中立位。双模型回放同时加载本轮四份可求解结果，分别显示各侧视觉方向。旧右臂引导录制只分析其显式参与设备，不能从同时在线但未参与动作的设备推断左臂结果。

可只读分析已完成且保存了实际运行矩阵的旧引导录制；旧分析结果不能跨积分器/相机会话应用。不要强行启用失败结果。

窗口内可点击「加载已有引导录制 · 离线重新计算」，选择原录制目录重新分析和回放。重启软件后积分参考系已改变，旧录制只能离线核查，不能以人工复核确认绕过会话检查。需实时应用时应在新会话重录。

```bash
conda run --no-capture-output -n OptUSBProj-fusion python -u OptUSBProj-ubuntu/visual_wearing_analyze.py \
  OptUSBProj-ubuntu/recordings/某次完整引导录制 \
  --output OptUSBProj-ubuntu/recordings/analysis_wearing/新目录
```

训练只用第一次中立、前举、侧举的静止保持窗口，去除窗口开头0.5秒和末尾0.2秒。准备、过渡、重复动作、自由验证均不参加安装拟合。原 IMU 基线使用同样的首次三姿势及重复/回中立验收，不用另一份录制。

## 数学约定

R(t) 将设备本体系 S 转到该设备积分参考系 W；Q 将 W 转到相机光学系 C。用真实 RGB-D 骨段方向联合估计 Q 与固定骨轴 b：

$$
\mathbf d_C(t)\approx Q R(t)\mathbf b_S,\qquad
Q=\exp([\mathbf k_C]_\times\psi)Q_g,\quad \|\mathbf b_S\|=1.
$$

复用原相机拟合器的多初值、soft-L1 和可观测性验收，但严格划分训练/验证。它不预设自然下垂骨段沿重力。

中立肩髋方向提供 Z 向上估计，右肩到左肩的水平投影提供 Y 向左，X=Y×Z。三根轴在 C 中的坐标组成矩阵的列，其转置为 K（C→M）。这里仍假设用户站直；肩髋表面观测不等于相机物理重力。

对于每段，以首个保持窗口平均原始姿态 R0 定义：

$$
\mathbf n_0=KQR_0\mathbf b_S,
\qquad L\mathbf n_0=-\mathbf e_z,
\qquad B=LKQR_0.
$$

L 取将 n0 转到模型下垂方向的最短旋转。它是明确的中立归一化约定，不宣称真实下垂严格竖直，也不测量解剖学轴向扭转零位。

运行时继续复用姿态引擎：

$$
U(t)=B[R_0^{\mathsf T}R(t)]B^{\mathsf T},
\qquad
U(t)(-\mathbf e_z)=LKQR(t)\mathbf b_S.
$$

后一式保证标定方向模型与人体渲染使用同一条几何关系。固定积分参考系改变 R'=AR、Q'=QAᵀ 时，B 不变。普通 GUI 归零保留 B，改变运动参考；如需复查标定精度，应使用录制时的共同中立位。

上臂/前臂分别归一化，其 L 可能不同，所以相对肘旋转不保证绝对解剖学准确。回放中需额外检查肘部一致性，不能只看肩腕方向误差。

## 验收和边界

- 每个静止窗口至少30包；姿态波动P90≤5°，陀螺模长P90≤20°/s，加速度模长中位距1g≤0.2g。
- 每个首次/重复保持窗口至少5帧可靠视觉配对；不跨100ms IMU间隙插值，不外推。
- 首次拟合：方向误差中位<12°、P90<25°，至少10帧水平投影足够，雅可比最小奇异值>0.03。
- 再前举、再侧举、回中立独立方向误差中位<12°、P90<25°。
- 自由验证至少10帧：中位<15°、P90<30°；设备回中立整体旋转偏差≤15°。
- 身体诊断按每个静止动作窗口分别统计，不再把不同动作、肩部变化与躯干转向混成一个整体转角。可靠观测要求至少5帧、覆盖率≥60%、窗口P90波动≤8°。
- 肩髋中心方向单独检查倾斜：可靠且窗口倾斜中位>12°拒绝；P90>5°进入人工复核。初始站直假设仍保留。
- 肩线、髋线分别相对于各自中立基准计算水平航向。两者同向、各自中位幅度>12°且差≤8°才提示共同转向；肩线>12°而髋线≤8°提示局部肩变化/表面深度偏差，不据此认定整体转身。方向冲突、观测不足或不稳定均进入「无法可靠核验」复核状态。
- 已分配躯干IMU时，使用同参考系中立/动作窗口的相对旋转补充核验；少于30包、参考系变化等不能冒充稳定或充当GT。没有躯干IMU仍可用视觉诊断。
- 单独肩线变化、共同转向、视觉肘弯曲P90>25°或缺少肘部核验均属于动作协议警告，不直接否决方向一致性良好的安装拟合。核心拟合或独立复测失败仍禁止应用。
- 候选映射与原映射相差>45°进入人工复核，不把原映射当作GT强行拉回。

结果分三级：「通过」、「通过，但需人工复核」、「需重录」。第二级允许预览，只有用户打开本次回放并明确勾选复核确认才允许应用；第三级即使确认也禁止应用。报告分别保存硬失败、复核原因、逐窗口倾斜/肩线/髋线可靠性和可选躯干IMU指标，不把未知观测当作身体没动。应用事件包含复核确认标志；设备/参考系/相机会话检查不变。

这些误差是与带噪声RGB-D方向的一致性，不是GT精度。遮挡、衣物表面、深度混合、肩关节中心误差、未硬件同步及标定期间航向漂移仍会影响结果。相机只有骨段两个端点，不能验证真实轴向扭转；当前不扩展手掌或腿部。

穿戴标定与航向标定仍是两个流程。完成本流程后，可另开「相机标定」选择双臂或单臂，录制并应用合格结果，再逐部位选择「陀螺＋加计＋RGB-D」。相机标定现已支持左右上臂/前臂；完成穿戴标定本身不会自动启用航向纠偏。

实时航向纠偏仍使用其独立 Q、骨轴及生命周期，穿戴映射应用不会偷偷覆盖它。相机或绑带变化需重标；普通归零不等于重新估计安装。若从纯IMU切换到已有融合流，仍应在规范姿势核对共同中立位。

## 验证状态

新增合成测试覆盖：12°非竖直中立骨轴恢复、相机任意倾斜、矩阵共轭/参考系不变性、验证不参与拟合、失败/过期拒绝、部分应用与原子验收、撤销以及双模型使用实际记录姿态而非重新积分。

已有真实引导数据可只读分析和回放，但这不代替用户对新映射的穿戴/轴向运动验收。没有把验证残差当作机器人真机精度或安全证明。
