# RGB-D 多人画面：人物选择与短时锁定

RTMW 与 YOLO26 都支持本功能。几何关联不需要新依赖；可选 OSNet 外观恢复需要本地源码与权重、PyTorch 和 CUDA。真实深度、三维质量门控、穿戴／相机标定及低频纠偏仍走原流程；只将选定目标的二维关键点送入深度反投影。

## 如何操作

1. 启动 RGB-D GUI、开启“三维观测：二维关键点＋真实深度”。
2. 单人首次自动锁定。多人时显示橙色人物框和本帧编号，但不输出任意一人的有效骨架。
3. 点击彩色预览中的人物框，或在人物下拉列表中选择；“锁定所选人物”也可确认当前列表项。主窗口和脱离后的独立相机窗口均支持点击。
4. 绿色框及 `TARGET` 表示当前跟踪目标。编号是本帧检测顺序，不是永久 ID；必须选择佩戴当前分配 IMU 的人。
5. 建议先选人，再执行穿戴＋相机一体标定。录制、标定／分析、历史恢复、自然掌面采样及 X1 随动期间不允许手动切换目标。
6. “取消选择 / 暂停视觉”不影响 IMU 积分及原始 RGB-D 采集；“单人自动（重新锁定）”重新进入只允许一人时的首次自动选择。

开启深度预览时不能通过深度图点选，因为显示像素不应直接冒充原始彩色像素；可使用下拉列表，或返回彩色预览再点击。画面留白点击无效，旧检测帧超过一秒拒绝选择。

## 跟踪不是每帧取同一编号

检测框顺序可能改变。锁定维护的是目标上一帧的框与表面深度，不是数组索引：

- 用原始图像归一化框进行关联：IoU 至少 0.25、框中心移动不超过上一框对角线的 0.35 倍、宽高变化比例在 0.35–3 内。全人体框包含伸展的手臂，不是刚体尺寸；旧 0.6–1.7 门槛可能在平举时误拒。中心和深度连续性仍保留。
- 两帧都有可靠表面深度时，差值不能超过 0.35 m。深度取框内躯干网格的中位数，经过彩色畸变／配准深度像素转换；不是骨骼关节中心，也不是人体身份特征。
- 多个候选满足关联，或目标与旁人明显重叠且无法用深度区分时，按歧义处理。
- 不到阈值、无检测或超过一秒无连续帧时，进入暂停状态。没有可用 OSNet 外观参考时仍需显式重新选择；启用 OSNet 后按下节验证恢复，绝不因只剩一人就直接恢复。

RTMW 仍检测所有人，但只对选中的一个框计算姿态；YOLO 使用相应检测框那一行关键点。无有效目标时输出无效点，不用上一帧骨架冒充当前观测；相机停止新增纠偏，IMU 继续传播，已累计修正保持。

## OSNet 外观验证恢复（实验）

官方模型定义：`no-improtent/deep-person-reid/torchreid/models/osnet.py`；权重：`no-improtent/reid-models/osnet_x1_0_msmt17.pth`。来自 [官方项目](https://github.com/KaiyangZhou/deep-person-reid) 与 [作者权重仓库](https://huggingface.co/kaiyangzhou/osnet)。不导入整个 torchreid 包，也不在运行时联网下载。模型使用 RGB、256×128、ImageNet 归一化，输出归一化 512 维外观向量，批量 CUDA 推理。源码与权重哈希记入帧 diagnostics。

本地资源齐全时工作线程自动启用；缺少资源、依赖或 CUDA 时明确提示，仍保持保守几何策略。每次显式选择会清空外观参考。先保存 3 个干净、深度有效的初始参考，再在唯一几何匹配、没有重叠、双方深度有效且当前与上一帧外观相似度 ≥0.8 时，保存有差异的动作参考（与参考集最大相似度 <0.97）。最多 20 份；前 3 份保留，其余槽位循环替换。至少收集 3 帧才允许恢复。参考在首次丢失/歧义后冻结，不在遮挡或恢复中学习旁人的外观。

**连续跟踪与丢失后重识别使用不同规则。** 正常连续跟踪依靠唯一几何关联、时间与深度连续性，不用 OSNet 0.85 作为每帧否决条件：抬臂等动作会改变人物框与外观，同一人的分数也可能显著下降。外观仍记录为 `reid_tracking_similarity`；骤变帧不会满足上述外观参考更新条件。没有发生歧义的几何关联也不是身份认证，另一个人在相近位置/深度悄然替代原人仍可能误关联。

暂停时继续检测所有人物，并对候选外观与参考集做余弦比较。只有同时满足以下条件才恢复：

- **仅丢失后的恢复**要求最佳相似度 ≥0.85，且比第二候选高 ≥0.08；无第二人并不免除相似度要求。
- 深度双方有效且差 ≤0.6 m；归一化框中心位移 ≤0.4、宽高比在 0.35–3 内。
- 与旁人没有无法用深度区分的明显框重叠。
- 连续至少 5 帧、跨越至少 0.4 秒；帧间隔 ≤0.5 秒，候选框连续 IoU ≥0.4。任何失败/无检测都会重置确认计数。
- 距最后可靠跟踪不超过 30 秒；超时继续暂停，需人工重新选择（现有显式选择仍要求重新相机标定）。

成功恢复不改变 `target_id` / `vision_epoch`、不调用标定失效逻辑，所以原相机标定和累计修正保持有效。恢复的骨架继续经过真实深度、骨长、时间同步及纠偏原有低通/限速门控。人物恢复不保证每个骨段立即通过质量门控。

阈值是待实测验证的工程初值，不是身份概率，也不是生物识别认证。相似衣服、严重遮挡、背景占比过大或穿戴者大幅移动仍可能误拒或误认；不能用作真机身份安全保证。首版不含人脸、IMU 动作一致性验证或跨程序运行的身份保存。

## 标定与记录

每次普通显式选择、取消或重新自动锁定都会更新视觉会话 `vision_epoch`，停用旧相机纠偏资格，并拒绝旧会话的推理结果和标定报告。穿戴轴映射、设备积分器与当前累计修正不清零。**真正换人之后需要重新进行相机标定**，不能无条件继续沿用之前人物的结果；确认恢复同一穿戴者可使用下面的独立快捷操作。

### 人工确认原标定者并恢复（不重新标定）

若恢复的是同一穿戴者、相机及绑带未移动，可使用主窗口的独立恢复操作，而不是再次计算标定：

1. 先停止 X1 随动、录制或正在进行的标定/分析；保持原相机采集会话和设备积分器运行。
2. 开启三维观测，在当前彩色人物列表中选择原标定者。普通锁定操作仍可能显示“标定已停用”，这是身份切换保护。
3. 勾选“确认所选为原标定者，相机和设备绑带未移动”。物理安装是否移动无法由软件完全验证，必须由用户确认。
4. 点击“确认原标定者 · 保留标定并恢复纠偏”。无需重新录制标定。

恢复前检查：原相机 capture epoch 未改变；原部位设备 ID、积分 epoch、重力参考、连续穿戴矩阵及手动轴映射仍一致；设备数据和候选人物框新鲜。按钮不可用时，悬停查看原因。缺少原标定或发生硬失效时拒绝恢复。

普通人物选择造成的暂停可恢复；相机停止/重启、明确点击“相机/穿戴变化：停用本次相机标定”、新标定未通过的部位等硬失效不能被后续人物选择覆盖，必须重新标定。仅恢复仍有资格的部位，按钮反馈恢复数量。

#### 在线切换模型、权重或输入尺寸

仅更换视觉后端不改变相机坐标系或设备安装，因此保留原 $Q$、骨轴及累计补偿，但暂停新增纠偏。新模型加载后，选择原标定者并使用上述确认按钮，在15秒内斜前举/侧举，让参与骨段清晰可见。各部位分别检查：至少20帧、跨越至少1秒、有效帧间隔不超过0.5秒；原有深度、置信度、骨长、同步及重力/穿戴检查仍生效，近竖直骨段（水平分量小于0.3）不计入样本。检查期间不更新补偿。

对新观测 $d_C$，比较保留补偿下的预测 $H_C(\delta)Q R b_S$ 与 $d_C$ 的方向夹角；中位数小于12°且P90小于25°时恢复该部位资格，下一帧按正常门控纠偏。超时或不一致则保持停用，可调整姿态后重新确认重试，仍不通过则重标定。一次举臂检查只证明该短窗口的一致性，不保证新后端在所有姿态下与旧模型同样准确，也不能区分视觉模型偏差和暂停期间的IMU漂移。

模型切换不能覆盖相机/设备/穿戴的硬失效；切回原模型也需要检查。原报告的签名不被改写。检查开始、通过、失败及各部位误差写入实时事件记录。

恢复保持累计角、融合修正矩阵、IMU 积分器、姿态算法和机器人启动状态不变。创建新的人物选择 epoch、清空旧待显示骨架和重建外观参考，旧人物推理结果不能进入新反馈。新骨架到达后仍执行原骨长/深度/同步、航向创新、低通及限速门控，不保证每个骨段立即更新。人工确认是用户承担身份判断的快捷通道，不是自动生物身份认证。

未经这一步确认，真正换人仍必须重新标定。原报告的旧视觉会话标识不会被改写；它不能因此作为新会话报告再次无条件应用。

在录制／标定中，目标丢失期间视觉观测无效，可能导致本轮标定需要重录；通过外观恢复验证后才能继续使用原目标观测。录制的 `vision.jsonl` 每帧 diagnostics 保存人物框、深度、源帧时间、选择模式、目标会话 ID、所选框索引、拒绝原因及可用时的外观相似度/恢复标志；manifest 保存 `person_target_at_start`。回放展示保存的检测和选择，不重新选择人物。

目标 ID 是选择会话标识，不是身份认证。现有离线比较工具不自动推断录制中的人物身份；未提供选择器时仍执行严格单人策略。

## 验收建议

先单人标定并确认纠偏，再让第二人从画面侧边进入：目标应保持原人。测试交叉/遮挡后原目标回到附近：暂停后显示多帧验证，确认成功才恢复原目标纠偏，无需重标定。测试只有旁人留下、相似衣服、缺少深度和丢失超过 30 秒：不得随意恢复。确认显式重新选人后旧相机结果不可继续应用。测试脱离预览窗口、窗口缩放和上下／左右留白，点击仍应选中对应原图中的框。
