## 2. 协议格式

### 2.1 读取格式

#### 2.1.1 数据解析

- 数据以**十六进制（HEX）格式**发送，不是 ASCII 码。
- 每个数据按**低字节在前、高字节在后**的顺序依次传输，两者组合成一个**有符号 short（int16）** 型数据。

  例如数据 DATA1，其中 DATA1L 为低字节、DATA1H 为高字节，换算方法如下：设 DATA1 为实际数据，DATA1H 为其高字节部分，DATA1L 为其低字节部分，则：

  ```
  DATA1 = (short)((short)DATA1H << 8 | DATA1L)
  ```

  这里必须注意：**移位前需要先把 DATA1H 强制转换为有符号 short 型数据**，DATA1 的数据类型也是有符号 short 型，这样才能正确表示负数。

#### 2.1.2 读取寄存器返回值

用于读取用户指定寄存器的值。**读取 REG1 会返回 REG1～REG4 共四个寄存器的值**，协议规定必须返回四个寄存器。

**发送指令：**

```
FF AA 27 REG 00
```

**返回格式如下：**

| 字节 | 0x55 | 0x5F | REG1L | REG1H | REG2L | REG2H | REG3L | REG3H | REG4L | REG4H | SUM |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

| 名称 | 说明 | 备注 |
| --- | --- | --- |
| REG1L | 寄存器 1 低 8 位 | REG1[15:0] = ((REG1H<<8)\|REG1L) |
| REG1H | 寄存器 1 高 8 位 | |
| REG2L | 寄存器 2 低 8 位 | REG2[15:0] = ((REG2H<<8)\|REG2L) |
| REG2H | 寄存器 2 高 8 位 | |
| REG3L | 寄存器 3 低 8 位 | REG3[15:0] = ((REG3H<<8)\|REG3L) |
| REG3H | 寄存器 3 高 8 位 | |
| REG4L | 寄存器 4 低 8 位 | REG4[15:0] = ((REG4H<<8)\|REG4L) |
| REG4H | 寄存器 4 高 8 位 | |
| SUM | 校验和 | SUM = 0x55+0x5F+REG1L+REG1H+REG2L+REG2H+REG3L+REG3H+REG4L+REG4H |

**示例：**

读取寄存器 `AXOFFSET`，返回：

```
0x55 0x5F AXOFFSET[7:0] AXOFFSET[15:8] AYOFFSET[7:0] AYOFFSET[15:8]
AZOFFSET[7:0] AZOFFSET[15:8] GXOFFSET[7:0] GXOFFSET[15:8] SUM
```

#### 2.2.2 写寄存器格式（HEX 码格式）

- 该方式更加灵活，可以操作每一个寄存器，但**容易设置错误**。设置前需要了解每个寄存器的含义，且只支持单项设置。对于多项设置（如账号密码），需要发送多个寄存器，会浪费大量数据交互时间。
- 以下数据均为 **Hex 码**。
- **所有设置都需要先解锁寄存器（KEY）。**

| 协议头 | 协议头 | 寄存器地址 | 数据低 8 位 | 数据高 8 位 |
| --- | --- | --- | --- | --- |
| 0xFF | 0xAA | ADDR | DATAL[7:0] | DATAH[15:8] |

- 数据以十六进制格式发送，不是 ASCII 码。
- 每个数据按低字节、高字节的顺序依次传输，两者组合成一个有符号 short 型数据。换算方法：设 DATA 为实际数据，DATAH 为高字节，DATAL 为低字节，则：

  ```
  DATA = (short)((short)DATAH << 8 | DATAL)
  ```

  同样需要注意：移位前需要先把 DATAH 强制转换为有符号 short 型数据，DATA 的数据类型也是有符号 short 型，这样才能表示负数。

**示例：（加速度校准）**

> 模块必须**正面朝上**放置才能进行加速度校准。如果反面朝上校准，会导致加速度异常，进而导致角度异常。

1. 进入校准：`FF AA 01 01 00`（校准使用 0x01 寄存器，后文详述）
2. 延时 5 秒
3. 退出校准：`FF AA 01 00 00`
4. 保存校准：`FF AA 00 00 00`

> **译者注**：原文仅说明"所有设置都需要先解锁寄存器（KEY）"，但未给出解锁寄存器的地址与数值。实际使用中（本工作区 `wt901/registers.py` 已验证）解锁方式为向寄存器 `0x69` 写入 `0xB588`。

##### 2.2.2.2 CALSW（校准模式）

- 寄存器名：CALSW
- 寄存器地址：1（0x01）
- 读写方向：R/W
- 默认值：0x0000

| 位 | 名称 | 功能 |
| --- | --- | --- |
| 15:4 | | |
| 3:0 | CAL[3:0] | 设置校准模式：<br>0000 (0x00)：正常工作模式<br>0001 (0x01)：自动加计校准<br>0011 (0x03)：清除高度（本版本无此功能）<br>0100 (0x04)：航向角归零<br>0111 (0x07)：磁场校准（球面拟合法）<br>1000 (0x08)：设置角度参考<br>1001 (0x09)：磁场校准（双平面模式，本版本无此功能） |

示例：`FF AA 01 04 00`（航向角归零）

**加计校准示例：**

```
FF AA 01 01 00      （进入校准，请确保模块水平放置）
等待 5 秒，自动校准完成
FF AA 01 00 00      （退出校准）
FF AA 00 00 00      （保存）
```

**磁场校准示例：**

```
FF AA 01 07 00      （进入磁场校准）
绕各轴朝北方向旋转 1～2 圈，请参考磁场校准视频
FF AA 01 00 00      （退出磁场校准）
FF AA 00 00 00      （保存）
```
